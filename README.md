# AlbumMod
AlbumMod for Idol Manager
DESCRIPTION
Album Mod Lite expands the music release system in Idol Manager by adding a more stylish and immersive album experience. The mod improves how singles and albums are displayed, adds custom album visuals, and introduces a polished K-pop inspired presentation style for releases. Every 6 songs turns into a album, it combines the sales of 6 singles into album. Which will give you a little banner, if reached a certain amount of sales. It will only show 1 - 3 members on the album cover. The center in your formation will be the center of the album cover. The first single you release will be the title track highlighted in yellow. the cover background changes when you pick a certain genre. E.g pop genre - Pink.

‼‼‼Open the album popup (Press F6)‼‼‼

Features

Custom Album Cards
Generates enhanced album cards with:
Group name display
Album title
Genre styling
Rank visuals
Custom cover layouts
Dynamic Album UI
Adds a new album browsing interface with:
Scrollable album panels
Detailed album information screens
Better organization for released music
Improved visual presentation
K-pop Style Presentation
Includes K-pop inspired album cover layouts and idol positioning.
Uses idol portraits and group visuals to create more unique release artwork.
Rank & Genre Color System
Albums and singles receive custom color styling based on:
Release rank
Genre type
Special visual effects help rare or high-performing releases stand out.
Sparkle & Visual Effects
Animated sparkle effects are added to album cards and release screens for a more premium presentation.
Automatic Album Generation
Builds virtual album collections using existing released singles.
Tracks releases and organizes them into album-style displays automatically.
Improved Release Details
Expanded release detail windows showing:
Sales information
Release dates
Song lists
Group data
Technical Details
Built using:
BepInEx
Harmony
Unity UI
Compatible with Idol Manager modding framework.
Goal of the Mod

Album Mod Lite was created to make music releases feel more alive, modern, and visually engaging while keeping the original Idol Manager gameplay intact.

It is designed for players who want a more immersive idol industry experience with stronger visual identity for their groups and releases.
